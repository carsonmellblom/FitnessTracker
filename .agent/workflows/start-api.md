Start the FitnessTracker API:

1. Navigate to the API project and run it:
```powershell
cd d:\dev\FitnessTracker\src\FitnessTracker.API
dotnet run
```

The API will be available at:
- API: http://localhost:5067
- Swagger: http://localhost:5067/swagger

Note: Make sure you have configured `appsettings.Development.json` with your PostgreSQL password first.
